# BlazorDesignToolkit.Primitives.StarterStyles

Optional starter CSS for BlazorDesignToolkit primitives, in the `bdt-starter` cascade layer and driven by `--bdt-*`
custom properties. Reference `_content/BlazorDesignToolkit.Primitives.StarterStyles/bdt-starter.css` and map the
variables to your tokens, or omit the package entirely.
