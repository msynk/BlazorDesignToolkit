# BlazorDesignToolkit.Theming

Browser-independent theming on top of BlazorDesignToolkit.Tokens: theme catalogs with brands and independent axes
(color mode, contrast, density, direction), conditional token layers, theme inheritance, DTCG resolver documents as
themes, deterministic theme stylesheets for every combination, and a runtime `ThemeManager`.

See https://github.com/msynk/BlazorDesignToolkit/blob/main/docs/theming.md
