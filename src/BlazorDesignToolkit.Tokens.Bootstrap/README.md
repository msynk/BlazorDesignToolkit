# BlazorDesignToolkit.Tokens.Bootstrap

Generates type-checked Bootstrap 5.3 Sass variables from DTCG tokens, and runtime `--bs-*` variables for every theme and
mode (with `-rgb` companions, the derived subtle/emphasis colors and button states Bootstrap computes in Sass) plus a
component bridge, so compiled components such as `.btn-primary` follow runtime theme switches. See https://github.com/msynk/BlazorDesignToolkit/blob/main/docs/integrations.md
