# BlazorDesignToolkit.Primitives

Accessible, unstyled Blazor primitives following the WAI-ARIA Authoring Practices: toggle button, checkbox, switch,
radio group, tabs, disclosure, accordion, dialog, popover, tooltip, listbox, select, menu with submenus, menubar,
combobox, command menu, tree view, slider, range slider, number field, date picker, toasts, live regions, form fields,
roving focus and focus trap. Listbox and tree view virtualize long lists. Built-in texts are localizable through
`PrimitiveStrings`. Semantic HTML first; no CSS framework.

API and accessibility contracts: https://github.com/msynk/BlazorDesignToolkit/blob/main/docs/primitives.md
