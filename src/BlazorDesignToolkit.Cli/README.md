# bdt

Command-line tool for BlazorDesignToolkit: `validate`, `build`, `export`, `coverage`, `diff`, `check` and `rules`
for DTCG 2025.10 tokens and themes, with text, JSON, GitHub-annotation and SARIF output and conventional exit codes.

```bash
dotnet tool install --global BlazorDesignToolkit.Cli
bdt check --config bdt.config.json
```

See https://github.com/msynk/BlazorDesignToolkit/blob/main/docs/cli.md
